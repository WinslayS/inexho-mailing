INTERNATIONAL EXPATS HOUSES — AVAILABILITY TEMPLATE

1. Keep index.html and styles.css together. Open index.html in Chrome or Edge.
2. Click a photo placeholder to select a real property photo. Photos are embedded in your saved HTML.
3. Click Edit text to change details. Add property creates another editable card; Remove appears in edit mode.
4. Click Save edited HTML to download your current work as index.html. Keep it beside styles.css. Changes are not saved automatically.
5. Print / Save PDF opens your browser print window. Choose Save as PDF, scale 100%, background graphics ON, headers and footers OFF.
   A4: two rows per portrait page, repeated company contact details, no split cards.
   Square: 1:1 for the original ten-property layout. Adding more cards extends the poster vertically.

The supplied PDFs are TEMPLATE PREVIEWS: photo placeholders and sample property details from the supplied HTML. Replace photos and verify all details before publishing.
